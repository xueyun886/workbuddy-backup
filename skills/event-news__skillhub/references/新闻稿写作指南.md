## 一、格式规范

### 文档输出格式
新闻稿最终以 Word 文档形式交付，需严格遵循以下格式：

| 元素 | 规格要求 | 说明 |
|------|----------|------|
| 标题 | 黑体小三，居中 | 如有副标题，使用黑体四号 |
| 正文 | 宋体小四 | 主要内容区域 |
| 首行缩进 | 2字符（约0.74cm） | 仅正文段落适用 |
| 行距 | 1.5倍行距 | 全文统一 |
| 段前段后间距 | 0行 | 正文段落 |
| 页边距 | 上下2.54cm，左右3.17cm | 标准A4文档 |

### 标题层级规范
```
【一级标题】如"一、会议召开" — 黑体四号，居左
【二级标题】如"（一）领导致辞" — 宋体小四加粗
【正文段落】— 宋体小四，首行缩进2字符
```

### 段落结构
- **导语段**：开头空两格或不缩进，统领全文
- **正文段**：首行缩进2字符
- **段落长度**：每段100-200字为宜，避免过长或过短
- **段间衔接**：逻辑连贯，避免跳跃

### 标点符号位置
- 标点紧贴文字，不单独占格
- 顿号（、）、逗号（，）、句号（。）在字符左下方
- 引号（""）、括号（（））内容居中
- 破折号（——）、省略号（……）占两格

## 二、标点符号规范

### 双引号使用规范

**基本原则**：双引号用于引用特定名称、专有名词、强调内容。

| 使用场景 | 正确用法 | 错误用法 |
|----------|----------|----------|
| 活动名称 | "4·15"全民国家安全教育日 | 4·15全民国家安全教育日 |
| 文件名称 | 《关于推进XX的通知》 | 《关于推进XX的通知》 |
| 专有名词 | "自主可控"技术体系 | 自主可控技术体系 |
| 强调内容 | 坚持"安全与发展"并重 | 安全与发展并重 |
| 会议主题 | 聚焦"数字基石·聚力智造"主题 | 聚焦数字基石·聚力智造主题 |

**注意事项**：
- 中文内容使用「」或""，不混用英文引号
- 引号内再引用时，外层用「」，内层用""
- 引号不用于普通词语的强调

**错误示例纠正**：
```
❌ 错误：活动以"创新"为主题
✅ 正确：活动聚焦"数字创新"主题

❌ 错误：他强调要"创新"
✅ 正确：他强调要坚持创新驱动发展
```

### 破折号使用规范

**基本原则**：破折号用于解释说明、话题转换、声音延长。

| 使用场景 | 正确用法 | 说明 |
|----------|----------|------|
| 解释说明 | "某智能制造服务中心——为全市提供智能制造技术服务的专业机构" | 破折号后为定义或解释 |
| 补充强调 | "智能制造——这一核心技术的应用推广" | 突出关键内容 |
| 话题转折 | "与会嘉宾一致认为——" | 引出后续内容 |
| 职务全称 | [姓名]，[职务]——[单位] | 用于完整职务信息 |

**规范用法**：
- 破折号占两格，呈"——"形状
- 不使用"--"或其他变形
- 破折号前后不随意添加空格

**错误示例纠正**：
```
❌ 错误：XX公司（专业机构--成立于2020年）
✅ 正确：XX公司——专业机构，成立于2020年

❌ 错误：本次活动-由XX主办
✅ 正确：本次活动——由XX主办

❌ 错误：智能制造技术的--应用
✅ 正确：智能制造技术的应用
```

### 其他标点规范

**顿号使用**：
```
✅ 正确：政府、企业、行业协会代表
❌ 错误：政府、企业家、行业协会代表（并列词语需词性一致）
```

**分号使用**：
```
✅ 正确：本次活动具有三大特点：一是规模大——覆盖全市；二是层次高——多位领导出席；三是成果丰——签署多项协议。
```

**引号与标点位置**：
```
✅ 正确：与会专家指出："要坚持自主创新。"
❌ 错误：与会专家指出："要坚持自主创新"。

✅ 正确：会上发布了《关于推进XX工作的意见》。
❌ 错误：会上发布了「关于推进XX工作的意见」。
```

## 三、各类新闻稿要点

### 1. 会议活动类

**适用场景**：行业会议、论坛、研讨会、专题讲座、启动仪式等。

**核心要素**：
- 活动名称（准确全称）
- 时间地点
- 指导/主办/协办单位（按层级排列）
- 参会人员（领导层级和数量）
- 活动内容（主题、议程、亮点）

**注意事项**：
- 领导排名按行政级别
- 活动主题要明确
- 结尾体现活动成效或行业意义

---

### 2. 荣誉入选类

**适用场景**：获得奖项、入选名单、通过认证、获批资质等。

**核心要素**：
- 荣誉名称（权威机构颁发）
- 评选标准
- 企业优势
- 行业意义

**注意事项**：
- 不能夸大其词（"首创""唯一"需确认）
- 避免过度自夸
- 体现"引领示范"作用

---

### 3. 培训学习类

**适用场景**：内部培训、外部研修、专题学习、考察交流等。

**核心要素**：
- 培训主题
- 参与对象和人数
- 培训内容（课程、讲师、形式）
- 预期效果

---

### 4. 项目建设/科技创新类

**适用场景**：项目开工/竣工、技术突破、产品发布、科研成果等。

**核心要素**：
- 项目/技术名称
- 技术亮点
- 应用场景
- 经济效益/社会效益（用数据说话）

**注意事项**：
- 数据要可验证
- 突出技术创新价值
- 避免绝对化表述

---

### 5. 领导调研类

**适用场景**：上级集团领导、政府领导到公司或项目现场调研指导。

**核心注意事项**：
- 来访领导信息零差错（姓名、职务、随行人员）
- 路线和陪同人员要写清楚
- 领导讲话只写正面、指导性内容
- 本公司表态用"衷心感谢""坚决落实"等标准用语
- 发布前必须送审

---

### 6. 签约/合作类

**适用场景**：战略合作协议签署、银企合作、校企合作、产业链签约等。

**核心注意事项**：
- 法律效力表述要谨慎（"正式达成合作"需协议已盖章生效）
- 金额和条款需法务财务确认
- 双方排名不分先后
- 合作内容要写实（具体领域和项目）

---

### 7. 社会责任/公益类

**适用场景**：乡村振兴捐赠、抗洪抢险、志愿服务、助学活动等。

**核心注意事项**：
- 避免道德绑架（不写"终于得到救助"）
- 金额物资要明确合规
- 涉及弱势群体需注意隐私
- 体现长效机制

---

### 8. 人物风采/一线故事类

**适用场景**：优秀党员、技术能手、项目经理、班组事迹等。

**核心注意事项**：
- 避免个人崇拜
- 故事必须真实可查
- 不搞对比贬低
- 最后回归组织培养

---

## 四、职务称呼规范

### 基本原则

**禁止使用口语化称呼**，如"X总""X总们""领导们"等。

**正确格式**：[姓名]，[职务]；或仅用[职务]

### 职务全称规范

| 场合 | 正确称呼 | 错误称呼 |
|------|----------|----------|
| 首次出现 | [姓名]，[职务] | [姓名]总 |
| 后续出现 | [职务]或[姓名] | [姓名]总 |
| 多人并列 | [姓名1]、[姓名2]等 | X总和X总 |
| 领导排名 | 按行政级别从高到低 | 按年龄或资历 |

### 职务表述示例

```
✅ 正确表述：
- 某市智能制造协会秘书长张三
- 某技术有限公司代表
- 某省工业和信息化厅厅长张三
- 与会领导

❌ 错误表述：
- 张总、李总
- X总
- 各位总
- 领导们
```

### 党内职务与行政职务

**同时具有党内职务和行政职务的领导**，一般按以下原则处理：

| 情形 | 处理方式 |
|------|----------|
| 党内职务为主要身份 | 党内职务+行政职务，如"省委副秘书XX" |
| 行政职务为主要身份 | 行政职务，党内职务作为补充 |
| 一般场合 | 使用习惯称呼 |

## 五、政治正确用语

### 常用规范表述

| 场合 | 推荐用语 |
|------|----------|
| 感谢支持 | "在各级领导的关心指导下""在政府及行业主管单位的支持帮助下" |
| 企业表态 | "衷心感谢""坚决落实""绝不辜负" |
| 成效表述 | "取得显著成效""顺利实现预期目标" |
| 未来展望 | "持续深化""不断推进""助力高质量发展" |
| 活动意义 | "对行业发展具有重要意义""为XX工作奠定坚实基础" |

### 禁止使用

| 禁止用语 | 原因 |
|----------|------|
| "首创""唯一""第一" | 需官方认定，未经确认不可使用 |
| "显著成绩""巨大贡献" | 过度夸张，不符合新闻规范 |
| 涉及领导批评或负面信息 | 只写正面、指导性内容 |
| 绝对化表述 | 如"全部完成""彻底解决"等 |

## 六、发布前检查清单

### 内容检查
- [ ] 领导姓名、职务是否准确
- [ ] 单位名称是否规范
- [ ] 数据是否有据可查
- [ ] 发言顺序是否符合规范（政府在前）
- [ ] 是否需要送审

### 格式检查
- [ ] 标题黑体小三，居中
- [ ] 正文宋体小四，首行缩进2字符
- [ ] 双引号使用正确
- [ ] 破折号使用规范
- [ ] 职务称呼规范（无"X总"等口语化表达）

### 标点检查
- [ ] 标点符号使用正确
- [ ] 无错别字
- [ ] 数字使用规范（阿拉伯数字与汉字数字使用场景）
