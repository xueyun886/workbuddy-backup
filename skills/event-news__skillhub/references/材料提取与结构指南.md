## 一、信息提取流程

### 通用原则
1. **优先使用官方文件**：邀请函 > 议程 > 宣传材料 > 发言稿
2. **多方交叉验证**：同一信息在多个材料中出现时，以最高权威来源为准
3. **缺失信息处理**：如某项信息缺失，跳过该字段，不编造

### 提取优先级
| 信息类别 | 优先级 | 来源 |
|----------|--------|------|
| 活动名称 | P0 | 邀请函/议程标题 |
| 时间地点 | P0 | 邀请函/议程 |
| 指导/主办/承办/协办单位 | P0 | 邀请函/议程 |
| 核心主题 | P0 | 议程/宣传材料 |
| 关键数据/成果 | P1 | 宣传材料/发言稿 |
| 领导/嘉宾信息 | P1 | 发言稿/议程 |
| 活动亮点 | P2 | 宣传材料 |

## 二、发言稿分析

### ⚠️ 首要判断：发言者身份

**在提取发言稿内容之前，必须先判断发言者属于哪一方：**

| 发言者类型 | 身份说明 | 新闻稿处理 |
|------------|----------|------------|
| 政府领导 | 政府主管部门负责人 | 优先引用，体现政府权威声音 |
| 行业协会 | 行业协会秘书长/代表 | 可引用，体现行业指导 |
| 主办方领导 | 活动主办单位负责人 | 核心发言，交代活动背景和成果 |
| 承办方代表 | 具体执行方代表 | 可引用，体现执行能力 |
| 协办方代表 | 支持方代表 | 体现资源支持 |
| 参与企业代表 | 参会/参展企业代表 | 体现参与和贡献，感谢主办方 |

### 主办方领导发言
- **提取内容**：主办方身份、感谢用语、活动意义、对未来的展望
- **写作处理**：可作为新闻稿中领导讲话的素材，注意只引用正面、表述清晰的语句
- **区分责任方**：主办方 = 东道主，协办方/参与方 = 嘉宾

### 参与方代表发言
- **提取内容**：参与方身份、为何参与、合作意向、评价主办方
- **写作处理**：体现参与方的积极态度和行业认可，避免过度褒奖

### 发言稿结构要素
```
发言者：[姓名] [职务]
发言者所属：[政府/协会/主办企业/参与企业]
发言主题：[提炼一句话主题]
关键观点：
- [观点1]
- [观点2]
核心金句：[如有可引用的精彩表述]
```

## 三、活动议程分析

### 发言顺序判断

**根据议程顺序和发言人身份，判断新闻稿中的发言顺序：**

| 议程顺序 | 发言人 | 新闻稿位置 |
|----------|--------|------------|
| 第一位 | 政府/主管部门领导 | 必写，靠前 |
| 第二位 | 行业协会代表 | 政府之后 |
| 第三位 | 主办方领导 | 政府/协会之后 |
| 第四位及之后 | 承办/协办/参与方 | 可选写 |

### 议程项分类
| 议程类型 | 新闻价值 | 是否写入新闻稿 |
|----------|----------|----------------|
| 开场/主持 | 低 | 简略带过或省略 |
| 政府领导致辞 | 高 | 必写，体现规格和重视程度 |
| 行业协会发言 | 中高 | 可写，体现行业指导 |
| 主题演讲/报告 | 高 | 必写，提取核心观点 |
| 主办方总结发言 | 高 | 必写，体现活动成果 |
| 承办/协办方发言 | 中 | 可写，体现执行贡献 |
| 签约/授牌仪式 | 高 | 必写，活动重要成果 |
| 颁奖/表彰 | 中高 | 可写，视情况而定 |
| 合影/茶歇 | 低 | 不写 |
| 参观/考察 | 中 | 可写，体现活动内容 |
| 讨论/交流 | 低 | 不写或一笔带过 |
| 闭幕 | 低 | 省略 |

### 议程信息提取表
```
活动名称：[全称]
会议时间：[具体时间]
会议地点：[地点]

议程结构：
1. [时间] [议程项] - 主持人：[姓名]
2. [时间] [议程项] - 主讲人：[姓名] [职务] [所属单位]
...

发言顺序分析：
1. [第一位发言人及单位] → 新闻稿位置：前
2. [第二位发言人及单位] → 新闻稿位置：中
3. [第三位发言人及单位] → 新闻稿位置：中
4. [后续发言人及单位] → 新闻稿位置：后

重点议程：
- [高新闻价值的议程项1]
- [高新闻价值的议程项2]

可省略内容：
- [低新闻价值的议程项]
```

## 四、宣传材料分析

### 宣传稿类型判断
- **预热稿**：活动前的预告，突出主题和意义
- **成果稿**：活动后的总结，突出成效和数据
- **业务宣传稿**：介绍公司业务，与活动关联度待判断

### 提取内容
- **活动背景**：为何举办此次活动
- **核心数据**：参与人数、覆盖范围、签约金额等
- **亮点成果**：活动取得的重要进展
- **未来计划**：后续安排或长期规划

### 常见宣传稿内容提取
```
活动背景：[一句话说明为什么举办]
核心数据：
- 参与人数：[X]人
- 覆盖范围：[领域/地区]
- 关键成果：[签约/发布/成立等]

亮点内容：
- [亮点1]
- [亮点2]

未来计划：[如有]
```

## 五、活动信息汇总表

将所有材料提取的信息汇总为以下结构：

### 基础信息
| 字段 | 内容 | 来源 |
|------|------|------|
| 活动名称 | | |
| 活动时间 | | |
| 活动地点 | | |
| 活动类型 | 会议/论坛/签约/调研/培训/社区活动/比赛/其他 | |

### 组织架构
| 字段 | 内容 | 备注 |
|------|------|------|
| 指导单位 | 官方主管部门（可无） | 体现活动权威性 |
| 主办单位 | 主要组织方 | 通常1个 |
| 承办单位 | 具体执行方 | 可多个 |
| 协办单位 | 支持方（可无） | 体现资源整合 |
| 参与单位 | 参会/参展方 | 体现覆盖面 |

### 核心内容
| 字段 | 内容 |
|------|------|
| 活动主题 | 一句话概括 |
| 活动背景 | 为何举办 |
| 主要内容 | 3-5点 |
| 重要环节 | 签约/发布/授牌等 |
| 关键数据 | 量化成果 |

### 出席领导/嘉宾（按层级排序）
| 姓名 | 职务 | 所属单位 | 层级 | 发言顺序 |
|------|------|----------|------|----------|
| | | | 省/市/区/协会/企业 | 1/2/3... |

### 发言顺序汇总
```
新闻稿发言顺序：
1. [政府/主管部门领导] - [核心观点]
2. [行业协会代表] - [核心观点]（如有）
3. [主办方领导] - [核心观点]
4. [参与企业代表] - [核心观点]（可选）
```

### 提炼要点
| 类型 | 内容 |
|------|------|
| 活动亮点 | 最值得报道的点 |
| 可引用语句 | 领导原话或精彩表述 |
| 注意事项 | 需要特别处理的内容 |

## 六、新闻稿结构选择

### 4段结构（一般类型活动）
适用于：正式会议、论坛、签约、官方培训等

```
第一段【导语】：时间地点主体事件
- 交代5W：时间、地点、主办方、活动名称、核心主题

第二段【主体-政府意见】：政府领导意见 + 活动内容
- 政府/主管部门领导致辞要点（核心观点，优先）
- 行业协会发言（如有）
- 主办方总结性发言

第三段【主体-企业参与】：企业参与 + 重要成果
- 企业代表发言要点（体现参与和贡献）
- 签约/授牌/发布等重要环节
- 核心数据或里程碑成果

第四段【结尾】：总结与展望
- 活动意义（对行业/区域/企业）
- 下一步计划或长期愿景
```

### 6段结构（复杂/非正式活动）
适用于：社区活动、慈善活动、比赛赛事、户外活动、综合型活动

```
第一段【导语】：时间地点主体事件
- 同4段结构，但可增加更多背景描述

第二段【背景】：政策依据 + 举办原因
- 相关政策背景或社会需求
- 政府部门的支持与指导

第三段【内容】：政府指导 + 活动详情
- 政府部门指导内容
- 参与方介绍（按层级/规模排序）
- 主要环节/比赛项目/服务内容

第四段【高潮】：企业参与 + 重点环节
- 企业/社会组织参与情况
- 比赛结果/颁奖情况
- 重要签约/发布内容

第五段【反响】：各方评价
- 政府/主管部门评价
- 参与者反馈
- 受众/媒体反应

第六段【展望】：后续计划
- 政府部门的后续要求
- 企业的持续参与计划
- 长效机制或持续影响
```

### 结构选择决策树
```
活动是否正式？
├── 是（政府主办/央国企/行业峰会）
│   └── 选择4段结构
└── 否（社区/慈善/比赛/综合）
    └── 选择6段结构

活动是否复杂？
├── 是（多主题/多环节/多参与方）
│   └── 增加主体段落
└── 否（单一主题/短流程）
    └── 压缩为3段也可

新闻点是否集中？
├── 是（核心事件突出）
│   └── 按4段或6段结构
└── 否（多点分散）
    └── 提炼1-2个核心点，其他略写
```

### 各类型建议结构

| 活动类型 | 推荐段数 | 侧重点 |
|----------|----------|--------|
| 政府会议/论坛 | 4段 | 政府领导意见、政策解读 |
| 企业主办活动 | 4段 | 政府支持、主办方主导 |
| 签约/发布 | 4段 | 政府见证、合作内容 |
| 培训/学习 | 4段 | 政府指导、课程内容 |
| 社区/公益活动 | 6段 | 政策背景、惠民内容 |
| 比赛/评选 | 6段 | 政府支持、赛事亮点 |
| 考察/调研 | 4段 | 政府指示、调研成果 |
| 综合型活动 | 6段 | 多面兼顾、重点突出 |
