# 新闻稿生成技能

## 任务目标
根据用户提供的活动材料（发言稿、议程、宣传材料等），提取关键信息，生成符合政府或企业宣传规范的新闻稿。

## ⚠️ 首要前提：确认新闻发布者身份

**在开始生成新闻稿之前，必须明确：新闻稿是以谁的名义发布？**

| 发布者角色 | 含义 | 示例 |
|------------|------|------|
| 政府/协会主办方 | 活动由政府或行业协会主导组织 | 政府主办论坛、协会主办评选 |
| 企业主办方 | 活动由企业主导组织 | 企业主办发布会、企业承办政府活动 |
| 企业参与方 | 企业作为参与者之一 | 企业参会、企业获奖、企业参展 |

### 判断规则
- **谁主办、谁发布**：由谁主办的活动，新闻稿就以谁的角度撰写
- **主办方视角**：领导发言、致辞内容、单位名称优先
- **参与方视角**：强调参与、展示贡献、感谢主办方

### 发言稿角色对应

| 发布者 | 谁的发言稿在前 | 发言稿处理方式 |
|--------|----------------|----------------|
| 政府/协会主办方 | 政府领导发言 | 领导讲话为主，企业发言作为响应 |
| 企业主办方 | 主办方领导发言 | 主办方致辞为核心，可提及嘉宾 |
| 企业参与方 | 主办方领导发言 | 企业代表发言作为参与展示，感谢主办方 |

### ⚠️ 角色不明确时的处理
**如果用户没有说明新闻稿发布者的角色，必须先询问用户：**
> "请确认新闻稿以谁的名义发布？比如：XX政府/协会主办方、XX企业主办方、XX企业参与方？"

**禁止在未确认角色的情况下自行假设并生成新闻稿。**

## 📌 核心注意事项

### 1. 发言顺序原则：政府领导在前，企业在后
新闻稿中介绍活动内容时，必须遵守以下顺序：

```
【正确顺序】
1. 政府/主管部门领导讲话或致辞内容
2. 行业协会发言（如有）
3. 主办方（政府/协会）整体总结
4. 参与企业发言或企业贡献介绍

【常见错误】
- ❌ 企业致辞在前，政府领导在后
- ❌ 企业产品/业务介绍在前，政府指示在后
- ❌ 主办方讲话未突出，嘉宾发言喧宾夺主
```

### 2. 职务称呼规范

**严格禁止口语化表达**：

| 禁止使用 | 正确格式 |
|----------|----------|
| X总、X总们 | [姓名]，[职务] |
| 领导们 | 与会领导 |
| XX总和XX总 | [姓名1]、[姓名2]等 |

```
✅ 正确示例：
- 某市AI协会秘书长张三
- 某技术有限公司代表
- 某省人工智能管理局局长张三

❌ 错误示例：
- 张总、李总
- 各位总
- X总
```

### 3. 双引号使用规范

**用于引用特定名称、专有名词、强调内容**：

| 使用场景 | 正确用法 | 说明 |
|----------|----------|------|
| 活动名称 | "4·15"全民国家安全教育日 | 突出专有活动 |
| 文件名称 | 《关于推进XX的通知》 | 注意与书名号区分 |
| 专有名词 | "自主可控"技术体系 | 强调特定概念 |
| 会议主题 | 聚焦"数字基石·聚力产业"主题 | 引出核心主题 |

```
✅ 正确：与会专家指出"要坚持自主创新"
❌ 错误：与会专家指出：要坚持自主创新（冒号替代引号）

✅ 正确：活动聚焦"数字创新"主题
❌ 错误：活动以"创新"为主题（普通词语无需引号）
```

### 4. 破折号使用规范

**用于解释说明、补充强调、话题转换**：

| 使用场景 | 正确用法 |
|----------|----------|
| 解释说明 | "某智能制造服务中心——为全市提供专业服务的机构" |
| 职务全称 | [姓名]，[职务]——[单位] |
| 补充强调 | "智能制造——这一核心技术的推广" |
| 话题转折 | "与会嘉宾一致认为——" |

```
✅ 正确：本次活动——由XX主办——取得圆满成功
❌ 错误：本次活动-由XX主办（使用连字符）

✅ 正确：XX公司——专业机构成立于2020年
❌ 错误：XX公司（专业机构--成立于2020年）（括号内用破折号）
```

**破折号规范**：
- 破折号占两格，呈"——"形状
- 不使用"--"或其他变形
- 前后不随意添加空格

## 📄 文档格式规范

新闻稿最终以 Word 文档交付，需严格遵循以下格式：

| 元素 | 规格要求 |
|------|----------|
| 标题 | 黑体小三，居中 |
| 副标题 | 黑体四号，居中 |
| 正文 | 宋体小四 |
| 首行缩进 | 2字符（约0.74cm） |
| 行距 | 1.5倍行距 |
| 页边距 | 上下2.54cm，左右3.17cm |

**生成新闻稿时**，在 Markdown 中使用以下标记表示格式：
- 标题：`# 标题`（对应黑体小三）
- 副标题：`## 副标题`（对应黑体四号）
- 正文段落：自然段落（生成时确保首行缩进格式）

## 核心工作流程

### 第一步：信息提取
读取用户提供的所有材料，按优先级提取信息：
1. 邀请函/正式通知 → 活动名称、时间地点、组织架构
2. 活动议程 → 主要环节、重要议程项
3. 发言稿 → 领导讲话要点、核心金句（区分发言者身份）
4. 宣传材料 → 活动背景、关键数据、成果亮点

详细提取规范见 [references/材料提取与结构指南.md](references/材料提取与结构指南.md)

### 第二步：信息汇总
按以下结构汇总提取的信息：
- **基础信息**：活动名称、时间、地点、类型
- **组织架构**：指导单位、主办单位、承办单位、协办单位、参与单位
- **核心内容**：主题、背景、主要内容、重要环节、关键数据
- **出席信息**：核心领导/嘉宾（按层级排序）

### 第三步：结构选择
根据活动类型选择新闻稿结构：

| 活动类型 | 段数 | 侧重点 |
|----------|------|--------|
| 政府会议、论坛、签约、正式培训 | 4段 | 规格、内容、成果、意义 |
| 社区活动、慈善活动、比赛赛事 | 6段 | 背景、内容、高潮、反响、展望 |

### 第四步：新闻稿撰写
按照选定结构撰写，确保：
- 导语交代5W（时间、地点、主体、事件、原因）
- 政府领导意见在前，企业宣传介绍在后
- 突出重要环节（领导致辞、签约仪式、颁奖等）
- 省略非重要内容（自由讨论、茶歇、参观等）
- 体现政治站位和国企担当
- **职务称呼规范**（无口语化表达）
- **标点符号规范**（双引号、破折号使用正确）

详细写作规范见 [references/新闻稿写作指南.md](references/新闻稿写作指南.md)

## 新闻稿结构

### 4段结构（正式活动）
```
第一段【导语】：时间地点主体事件
- [时间]，[活动名称]在[地点]顺利举行/召开
- 交代指导/主办/协办单位
- 一句话说明活动核心主题

第二段【主体-内容】：政府领导意见 + 活动内容
- 政府/主管部门领导致辞要点（核心观点，优先）
- 行业协会发言（如有）
- 主办方总结性发言
- 主要议程/活动内容概述

第三段【主体-亮点】：企业参与 + 重要成果
- 企业代表发言要点（体现参与和贡献）
- 签约/授牌/发布等重要环节
- 核心数据或里程碑成果

第四段【结尾】：总结与展望
- 活动对行业/区域/国家的意义
- 下一步计划或长期愿景
- 体现责任担当
```

### 6段结构（复杂/非正式活动）
```
第一段【导语】：时间地点主体事件
- [时间]，[活动名称]在[地点]举行
- 交代主办单位
- 活动背景一句话

第二段【背景】：政策依据 + 举办原因
- 相关政策背景或社会需求
- 政府部门的支持与指导

第三段【内容】：政府指导 + 活动详情
- 政府部门指导内容
- 参与方介绍（按层级/规模排序）
- 主要环节/比赛项目/服务内容

第四段【高潮】：企业参与 + 重点环节
- 企业/社会组织参与情况
- 比赛结果/颁奖情况
- 重要签约/发布内容

第五段【反响】：各方评价
- 政府/主管部门评价
- 参与者反馈
- 受众/媒体反应

第六段【展望】：后续计划
- 政府部门的后续要求
- 企业的持续参与计划
- 长效机制或持续影响
```

## 使用示例

### 示例1：正式会议
- **输入**：政府指导的行业发展论坛，某企业参与，多位领导致辞
- **确认**：新闻稿以政府主办方角度撰写
- **发言顺序**：政府领导 → 协会发言 → 企业响应
- **输出**：4段新闻稿，政府声音贯穿全文

### 示例2：企业参与活动
- **输入**：企业参加政府主办的评选活动，获得荣誉
- **确认**：新闻稿以企业参与方角度撰写
- **发言顺序**：政府领导 → 主办方总结 → 企业成果展示
- **输出**：突出企业获奖，感谢主办方指导

### 示例3：公益活动
- **输入**：企业联合社区开展志愿服务活动
- **确认**：新闻稿以企业主办方角度撰写
- **发言顺序**：政府/街道指导 → 企业组织 → 居民参与
- **输出**：6段新闻稿，体现社会反响
