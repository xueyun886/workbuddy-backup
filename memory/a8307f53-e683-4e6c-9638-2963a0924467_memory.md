## Memory Block

**工作背景**
用户是长江大学园艺园林学院副院长（分管科研、学科建设、实验室、资产管理），同时担任办公室主任，承担公文、报告、致辞及国际合作备忘录撰写工作。专业背景为植物生物学、生物化学与分子生物学，长期担任研究基金申请项目评审专家或评审组成员。当前正撰写 AP2/ERF 转录因子调控植物萜类生物合成的英文综述论文，属植物分子生物学与生理学交叉方向。国际合作方面，主导与葡萄牙埃武拉大学的合作备忘录撰写，聚焦富硒农产品研发、共建实验室及博士/博士后联合培养；持续维护塔尔萨大学与长江大学 2024.8.21 版学术合作谅解备忘录作为措辞与格式参考。计算机环境为 Windows（用户名 ZWW），主用 Edge 浏览器访问学术/科研类站点，偏好助手直接执行系统级修改操作而非仅给指令说明。

**个人背景**
用户中英双语流利——SCI 论文、英文综述以英文撰写，交互、指令、评审及公文产出均偏好中文，中文评审意见固定控制在 100–400 字。文字要求极高：写作不空泛、逻辑清晰、措辞严谨、符合公文规范、精简多余"的"字；润色须自然流畅、彻底去除 AI 生成痕迹、绝不捏造数据。英文润色坚持"整词替换"原则，以完整单词为单位呈现修改；偏好"结论先行"结构——先列拼写/术语错误与修改说明，再给修改后全文。综述润色采用分节逐次打磨方式，用户提供编号小节标题（如 3.1、3.2、3.3...）按节推进。涉密材料仅限本地查阅，不得上传网络或云端。习惯为不同任务调用专属人设提示词（副院长/办公室主任/SCI 写作/学术写作/项目评审）精准匹配风格。深度调研采用"WebSearch + 搜狗微信公众号脚本（sogou_search.py）"多轮检索工作流。常驻荆州，关注当地天气。
