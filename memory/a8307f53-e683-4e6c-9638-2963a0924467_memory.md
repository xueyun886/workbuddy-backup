## Memory Block

**工作背景**
用户是长江大学园艺园林学院副院长，同时担任办公室主任，分管科研、学科建设、实验室、资产管理。专业方向为植物生物学、生物化学与分子生物学，长期从事该领域科研项目评审，是研究基金申请项目的评审专家或评审组成员。同时牵头学校国际合作事务，主导与葡萄牙埃武拉大学的合作备忘录撰写，聚焦富硒农产品研发、共建实验室及博士/博士后联合培养；持续维护塔尔萨大学等海外合作样板文本作为参照。计算机环境为 Windows 系统（用户名 ZWW），主用 Edge 浏览器访问学术/科研类站点，偏好助手直接执行系统级修改操作。

**个人背景**
用户中英双语流利——SCI 论文以英文撰写，交互、指令、评审及公文产出均偏好中文。文字要求极高：写作不空泛、逻辑清晰、措辞严谨、符合公文规范、精简多余 "的" 字；润色须自然流畅、彻底去除 AI 生成痕迹、绝不捏造数据。英文润色坚持"整词替换"原则，以完整单词为单位呈现修改。涉密材料仅限本地查阅，不得上传网络或云端。用户习惯为不同任务调用专属人设提示词（副院长/办公室主任/SCI 写作/学术写作/项目评审）精准匹配风格。常驻荆州，关注当地天气。

**当前关注**
在 WorkBuddy 平台（腾讯系 AI 助手环境）内批量评审项目申请书 PDF（编号 17、18、19、20+），逐份聚焦分析，按"科学问题 40% + 研究方案 40% + 研究条件与基础 20%"权重执行；中文评审意见控制在 100–400 字，结构化、有逻辑；分析结论输出为中文约 500 字单段总结。评审方向涉及柑橘黄龙病互作、苹果糖代谢、草莓耐热基因等园艺分子生物学议题。与此同时，正开展**香椿（Toona sinensis）全球科研与生产加工的深度调研**，覆盖基因组学、药理活性、加工技术等领域，采用"深度研究"工作流：WebSearch 叠加搜狗微信公众号搜索脚本（sogou_search.py）进行多轮关键词检索，成果以汇总表格或 Excel 等结构化形式呈现。文档模板遵循中英文对照 Word 版本与既有 PDF 模板（如塔尔萨大学 2024.8.21 版）统一格式与措辞。

- 在 WorkBuddy 平台按编号顺序逐份评审项目申请书（@17、@18、@19、@20…），涵盖柑橘黄龙病互作、苹果糖代谢、草莓耐热基因等项目。

- 新增**香椿（Toona sinensis）全球科研与生产加工深度调研**任务，覆盖基因组学、药理、加工等领域，采用 WebSearch + 微信公众号搜狗脚本（sogou_search.py）多轮检索工作流，偏好汇总表格与 Excel 等结构化呈现方式。
- 沿用分场景人设提示词策略（副院长/办公室主任/SCI 写作/学术写作/项目评审）与去 AI 化、反捏造、整词替换等质量标准，严格遵守本地文件不外传的保密要求。
- 推进长江大学与葡萄牙埃武拉大学国际合作备忘录撰写，围绕富硒农产品研发、联合实验室、博士及博士后联合培养展开，文档采用中英对照 Word 版本。
- 参考塔尔萨大学与长江大学 2024.8.21 版学术合作备忘录作为格式与措辞模板，撰写新文档时常参考已有 PDF 模板指导修改。
- 维护多线任务并行：园艺园林学院行政与学科事务、办公室主任公文产出、SCI 写作支持、项目评审、国际合作文本修订、香椿深度调研。
