## Memory Block

**工作背景**
用户是长江大学园艺园林学院副院长，分管科研、学科建设、实验室及资产管理。专业方向为植物生物学、生物化学与分子生物学，同时擅长SCI英文论文撰写与润色，以及正式公文（如报告、致辞）的撰写，具备学术写作与正式场合文体的双重能力。

**个人背景**
用户中英双语流利，SCI论文写作以英文为主，交互与指令偏好中文。对输出质量要求极高，强调写作不空泛、逻辑清晰、用词严谨、杜绝夸饰，符合公文规范，并精简多余"的"字。润色文本要求自然流畅，坚决去除任何AI生成痕迹，绝不捏造数据。英文润色坚持"整词替换"原则——以完整单词为单位呈现修改，不对单个字母修改；学术文本追求严谨性与专业语感，正式公文要求庄重典雅。涉密审查材料须本地处理，不得上传至任何网络或云端平台。用户习惯针对不同任务类型使用专属人设提示词（副院长、办公、SCI、学术、评审），以确保输出风格精准匹配场景。

**当前关注**
核心为"园艺植物种质创新与利用国际会议暨2026产学研用合作会议"的会议文件撰写与优化，此前已参与该会议并为长江大学领导撰写开幕式欢迎致辞。SCI论文润色方面，要求提升学术严谨性与专业性，严格执行整词替换规则，彻底去除AI痕迹，使语句具学术风格且符合人类学术作者的地道表达。正式公文方面，持续追求庄重典雅、逻辑严密的行文风格。科研评审方面，承担植物分子生物学与生理学领域的项目评审任务，需按科学问题40%、研究方案40%、研究条件与基础20%的权重给出评审意见，中文控制在100–400字。
