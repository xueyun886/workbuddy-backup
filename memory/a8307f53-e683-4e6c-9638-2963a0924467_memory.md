> Last updated: 2026-08-08T23:33:34+08:00

## Memory Block

**工作背景**
用户是长江大学园艺园林学院副院长，同时担任办公室主任，分管科研、学科建设、实验室、资产管理，并擅长公文、报告、致辞的撰写。专业方向为植物生物学、生物化学与分子生物学，长期从事该领域的项目评审工作。同时牵头长江大学国际合作事务，主导与葡萄牙埃武拉大学的合作备忘录撰写，聚焦富硒农产品研发、联合实验室建设及联合培养博士/博士后项目，并持续维护塔尔萨大学等海外合作样板文本。计算机环境为 Windows 系统（用户名 ZWW），主用 Edge 浏览器访问学术/科研类站点。

**个人背景**
用户中英双语流利——SCI论文以英文撰写，交互、指令及评审结论均偏好中文。文字要求极高：写作不空泛、逻辑清晰、措辞严谨、符合公文规范、精简多余"的"字；润色须自然流畅、彻底去除AI生成痕迹、绝不捏造数据。英文润色坚持"整词替换"原则，以完整单词为单位呈现修改，追求学术严谨性与专业语感；正式公文庄重典雅。涉密审查材料仅限本地查阅，不得上传网络或云端。用户习惯为不同任务调用专属人设提示词（副院长/办公/SCI/学术/评审）精准匹配风格，并偏好助手直接执行系统修改操作，而非仅提供操作说明。常驻荆州，关注当地天气。

**当前关注**
在 WorkBuddy 平台（腾讯系AI助手环境）内批量评审项目申请书PDF（编号17、18、19、20+），涉及柑橘黄龙病（CLas-citrus）互作、苹果糖代谢、草莓耐热基因等园艺分子生物学方向。每次聚焦一份PDF逐份开展分析，权重严格按"科学问题40% + 研究方案40% + 研究条件与基础20%"执行；中文评审意见控制在100–400字，结构化、有逻辑；分析结论输出为中文约500字、逻辑连贯的单段总结。与此同时，正推进长江大学—埃武拉大学合作备忘录的修订，文档采用中英文对照Word版本，撰写时需参考既有PDF模板（如塔尔萨大学2024.8.21版）维持格式与措辞统一。撰写新文档时倾向于参考已有PDF模板指导修改。

**近期动态**
- 在 WorkBuddy 平台按编号顺序逐份评审项目申请书（@17、@18、@19、@20…），涵盖柑橘黄龙病互作、苹果糖代谢、草莓耐热基因等项目。
- 确立评审输出规范：分析结论中文约500字单段总结，评审意见100–400字结构化呈现。
- 沿用评审权重（科学问题40% + 研究方案40% + 研究条件与基础20%）及分场景人设提示词策略（副院长/办公/SCI/学术/评审）。
- 持续强化去AI化、反捏造、整词替换等质量标准，并严格遵守本地文件不外传的保密要求。
- 推进长江大学与葡萄牙埃武拉大学国际合作备忘录撰写，围绕富硒农产品研发、联合实验室、博士及博士后联合培养等议题展开，文档采用中英对照Word版本。
- 参考塔尔萨大学与长江大学2024.8.21版学术合作备忘录作为格式与措辞模板，撰写新文档时常参考已有PDF模板指导修改。
- 维护多线任务：园艺园林学院行政与学科事务、办公室主任公文产出、SCI写作支持、项目评审、国际合作文本修订并行推进。
- Windows 系统用户名 ZWW，使用 Edge 浏览器频繁访问老旧 HTTP 学术/科研类站点，偏好助手直接执行系统级修改而非仅提供操作说明。
